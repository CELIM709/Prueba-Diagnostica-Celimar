## 1) Analizador de Expresiones Aritméticas (P1)

Clasifica los componentes de una expresión en:

* NUMERO
* OPERADOR (`+ - * /`)
* PAREN_IZQ / PAREN_DER
* OPERANDO
* ERROR

También valida el balanceo de paréntesis.

### Uso

Abrir el proyecto en NetBeans y ejecutar la clase principal.

### Ejecución

* Abrir **P1_Analizador** en NetBeans
* Ejecutar `P1_TokenAritmetico.java`
* Ingresar la expresión por consola

### Requisitos

* Java JDK 17+
* NetBeans

## 2) Validador de Notación FEN (P2)

Valida si una cadena cumple con la notación FEN.

* Verifica los 6 campos
* Valida estructura del tablero (8x8)
* Comprueba turno, enroque y contadores

### Uso

Ejecutar el programa e ingresar la cadena FEN.

### Ejecución

* Abrir **P2_ValidadorFEN** en NetBeans
* Ejecutar `P2_ValidadorFEN.java`

### Requisitos

* Java JDK 17+
* NetBeans

## 3) Conjetura de Collatz (P3)

Verifica la conjetura en un intervalo `[p, q]`.

* n par → n / 2
* n impar → 3n + 1
* Condición: `q ≥ 100p`

### Uso

Ingresar los valores solicitados por consola.

### Ejecución

* Abrir **P3_Collatz** en NetBeans
* Ejecutar `P3_ConjeturaDeCollatz.java`

### Requisitos

* Java JDK 17+
* NetBeans
